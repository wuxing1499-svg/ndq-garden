# AI 时代知识管理与提示词精粹

## 1. 结构化笔记原则（面向 RAG 优化）
1. **标题具体化**：大模型向量切片是按语义搜索的。标题应当明确表述核心议题（例如：《如何排查Docker在MacOS上的DNS问题》优于《Docker笔记》）。
2. **段落清晰分明**：每个子主题使用 `##` 或 `###` 区分，单段落建议 200~500 字，避免超长通篇不断句。
3. **关键信息前置**：在笔记正文第一段用 1~2 句话写出核心结论（TL;DR）。

## 2. AnythingLLM 专属 Workspace 提示词范例

在工作区设置的 **System Prompt** 中填入以下提示词，可以让 DeepSeek 表现更严谨：

```text
你是一个基于个人 Obsidian 笔记库的专属知识智囊助手。请遵守以下原则：
1. 你的回答必须严格基于提供的笔记上下文内容；
2. 回答中请指出引用自哪篇笔记（例如：【引用来源：《XXX》】）；
3. 如果检索到的笔记中没有相关记录，请诚实说明“笔记中暂无相关记录”，不要凭空捏造；
4. 输出格式尽量使用清晰的要点列举（Bullet points）和加粗重点。
```

## 3. 经典提问模板
- **梳理回顾**：“*请帮我总结一下《01_Projects》中目前有哪些尚未完成的任务和阻塞项？*”
- **概念检索**：“*根据我的笔记，关于 Docker 镜像拉取失败通常有哪些解决办法？*”
- **关联思考**：“*对比笔记中提到的 A 方案与 B 方案，各自的适用场景是什么？*”
